# Organizational Change Models

## Summary

This chapter names the major organizational change models used later in the book — Kotter's eight steps, Lewin's unfreeze-change-refreeze, ADKAR, Bridges' transition model, Schein's culture model, Senge's learning organization, Fullan's educational change, and the Concerns-Based Adoption Model — along with organizational and school culture. Readers finish able to name each model and what it is used for before studying any one in depth.

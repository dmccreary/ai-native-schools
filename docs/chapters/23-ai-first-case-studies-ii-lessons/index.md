# AI-First Case Studies II: Lessons for Practice

## Summary

This chapter presents a second set of cases focused on lessons for practice: AltSchool, Summit Learning, the Los Angeles iPad rollout and "Ed" chatbot, and other cautionary and positive examples, closing with how to evaluate result claims and make a recommendation to a school board. Readers finish able to use a past failure or success to write a risk checklist for a new pilot.

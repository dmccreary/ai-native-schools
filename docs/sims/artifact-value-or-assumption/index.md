## About This MicroSim

Edgar Schein describes organizational culture in three layers: *cultural artifacts* you can observe, *espoused values* the organization states, and *basic assumptions* that no one states but everyone acts on. You read eight statements about a school and place each in a layer.

Ask one question: can it be observed, is it stated, or can it only be inferred from behavior? In this set the stated values and the basic assumptions point in different directions, which is why assumptions usually win. The statements are illustrative, written for this chapter.

| Layer | Definition |
|---|---|
| Cultural artifact | Something visible or audible that you can observe directly |
| Espoused value | A belief or goal the organization states |
| Basic assumption | An unspoken, taken-for-granted belief, usually inferred from behavior |

## Lesson Plan

### Learning Objective

The learner will distinguish eight statements about a school as cultural artifacts, espoused values, or basic assumptions, correctly placing at least seven of eight on the first attempt. (Bloom level: Analyze.)

### Audience

Teachers, school administrators, school board members, education policymakers, and parents.

### Duration

10 minutes

### Prerequisites

- Cultural artifacts, espoused values, basic assumptions, and culture assessment, from the section "Culture, Assessed" in Chapter 18.

### Activities

1. **Predict (2 min).** Does a school's mission statement describe its culture? Write yes or no and why.
2. **Distinguish (5 min).** Place the eight statements. For each, ask whether it is observed, stated, or inferred.
3. **Discuss (3 min).** Find a stated value in the set that a basic assumption contradicts. Which one wins in practice?

### Assessment

Ask learners to answer without the MicroSim, then check each answer by using it.

1. The school day is divided into fifty-minute periods. Which layer? *(Cultural artifact: it is observable structure.)*
2. The handbook says parents are partners. Which layer? *(Espoused value: it is a stated belief.)*
3. Can basic assumptions be read off the walls? *(No. They are inferred from behavior.)*
4. Is a visible practice the same as a belief? *(No. The practice is an artifact; the belief behind it may be an assumption.)*
